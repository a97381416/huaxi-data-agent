# Skill 测试技能

## 用途
本技能用于验证 Skill 系统是否能够正确加载、解析和执行。

## 测试步骤

当被调用时，请按以下步骤执行并报告结果：

1. **加载测试**：确认本 SKILL.md 已被正确读取
2. **解析测试**：确认 frontmatter（name、description）被正确解析
3. **执行测试**：输出以下测试报告

## 测试报告模板

请输出如下格式的测试报告（使用 Markdown 代码块包裹）：

```markdown

## ✅ Skill 系统测试报告

---

| 检查项 | 状态 |
|--------|------|
| 技能加载 | ✅ 成功 |
| 元数据解析 | ✅ 成功 |
| - name | `skill-test` |
| - description | ✅ 已解析 |
| 指令执行 | ✅ 成功 |
| 当前时间戳 | `<当前时间>` |

---

**结论：Skill 系统工作正常 ✅**
```
