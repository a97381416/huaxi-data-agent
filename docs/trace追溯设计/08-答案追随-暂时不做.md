# **四、这里有一个实现细节，我特别提醒你**

不要只设计：

```
Fact → Tool Call
```

因为实际的 Agent 经常存在多级计算。

例如：

```
SQL-001：查询备案数量 19
       ↓
SQL-002：查询总数量 179
       ↓
Calculate-001：19 / 179 * 100
       ↓
最终回答：备案率 10.6%
```

应该支持：

**Fact → 中间计算 → Tool Call → 原始数据**

另外，同一个事实可能由多个 Tool 共同支持，因此事实与证据之间应该是多对多关系。
